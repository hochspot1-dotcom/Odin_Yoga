# MEOWMASTE — Премиум студия йоги

Современный, динамичный веб-сайт для студии йоги MEOWMASTE в изумрудно-зеленой неоновой стилистике (Dark Forest & Neon Emerald theme).

## 🌟 Особенности проекта
- **Hero-баннер на весь экран (Full-bleed)** с прозрачной навигационной панелью и вдохновляющей цитатой без необходимости прокрутки.
- **Карточки занятий ("Выбор клиентов")** с фоновыми фотографиями асан на полную ширину карточки, зеленым фильтром и интерактивными карточками.
- **Интерактивные неон-шары ("Почему это полезно?")** с чередованием залитых сфер с текстом и темных сфер с изумрудными неоновыми контурными силуэтами по референсному дизайну.
- **Плавный глобальный градиент** от глубокого лесного зеленого `#0a2216` до утонченного черного `#000000` в подвале.
- **Полная адаптивность**: адаптировано под десктопы, планшеты и мобильные устройства (смартфоны).
- **Матовая стеклянная кнопка «Записаться»** с модальным окном записи.

## 🚀 Запуск проекта
Просто откройте `index.html` в браузере или запустите любой локальный веб-сервер (например, Live Server или `npx http-server .`).
